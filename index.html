Admin Guide

管理员如何更新

这个网页没有后台数据库。管理员通过 GitHub 修改文件，普通访问者只能通过链接浏览网页。

1

更新球员

在 index.html 底部找到 players 数组，修改姓名、号码、位置、简介和照片地址。

2

更新动态

在 news 数组里添加新的球队动态，包括日期、标题、内容和图片。

3

发布网页

上传到 GitHub 仓库后，在 Settings → Pages 开启 GitHub Pages，即可获得公开访问链接。
